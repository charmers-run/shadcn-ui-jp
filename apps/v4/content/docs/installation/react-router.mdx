## shadcn/create

<Steps>

### プリセットのビルド

[shadcn/create](/create?template=react-router) を開いて、プリセットを視覚的に構築します。スタイル、色、フォント、アイコンなどを選択します。

<Button asChild size="sm">
  <Link
    href="/create?template=react-router"
    target="_blank"
    rel="noopener noreferrer"
    className="mt-6 no-underline!"
  >
    shadcn/create
  </Link>
</Button>

### プロジェクトの作成

`Create Project` をクリックし、パッケージ マネージャーを選択し、生成されたコマンドをコピーします。

生成されるコマンドは次のようになります。

```bash
npx shadcn@latest init --preset [CODE] --template react-router
```

正確なコマンドには、`--base`、`--monorepo`、`--rtl` などの選択したオプションが含まれます。

### コンポーネントの追加

`Card` コンポーネントをプロジェクトに追加します。

```bash
npx shadcn@latest add card
```

モノレポを作成した場合は `apps/web` からコマンドを実行するか、リポジトリのルートからワークスペースを指定します。

```bash
npx shadcn@latest add card -c apps/web
```

上記のコマンドは、`Card` コンポーネントをプロジェクトに追加します。次に、次のようにインポートできます:

```tsx showLineNumbers title="app/routes/home.tsx"
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "~/components/ui/card"

export default function Home() {
  return (
    <Card className="max-w-sm">
      <CardHeader>
        <CardTitle>Project Overview</CardTitle>
        <CardDescription>
          Track progress and recent activity for your React Router app.
        </CardDescription>
      </CardHeader>
      <CardContent>
        Your design system is ready. Start building your next component.
      </CardContent>
    </Card>
  )
}
```

モノレポを作成した場合は `apps/web/app/routes/home.tsx` を更新し、代わりに `@workspace/ui/components/card` からインポートします。

</Steps>

## CLI

<Steps>

### プロジェクトの作成

`init` コマンドを実行して、新しい React Router プロジェクトをスキャフォールディングします。プロンプトに従って、ベース、プリセット、モノレポなどのプロジェクトを構成します。

```bash
npx shadcn@latest init -t react-router
```

**モノレポ プロジェクトの場合は、`--monorepo` フラグを使用します。**

```bash
npx shadcn@latest init -t react-router --monorepo
```

### コンポーネントの追加

`Card` コンポーネントをプロジェクトに追加します。


## Existing Project

<Steps>

### プロジェクトの作成

新しい React Router プロジェクトが必要な場合は、先に作成します。既存のプロジェクトがある場合は、この手順を省略してください。

```bash
npm create react-router@latest
```

`create-react-router` はすでに Tailwind CSS とデフォルトの `~/*` インポート エイリアスを構成しています。 shadcn/ui を古いまたはカスタム React Router アプリに追加する場合は、続行する前に両方が構成されていることを確認してください。

### CLI を実行します

`shadcn` init コマンドを実行して、プロジェクトに shadcn/ui をセットアップします。

```bash
npx shadcn@latest init
```

### コンポーネントの追加

これで、プロジェクトへのコンポーネントの追加を開始できます。

```bash
npx shadcn@latest add button
```

上記のコマンドは、`Button` コンポーネントをプロジェクトに追加します。次に、次のようにインポートできます:

```tsx showLineNumbers title="app/routes/home.tsx"
import { Button } from "~/components/ui/button"

export default function Home() {
  return (
    <div className="flex min-h-svh flex-col items-center justify-center">
      <Button>Click me</Button>
    </div>
  )
}
```

</Steps>

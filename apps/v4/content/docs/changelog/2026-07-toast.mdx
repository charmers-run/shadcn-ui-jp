新しい [Toast](/docs/components/base/toast) コンポーネントが Base UI プロジェクトで利用できるようになりました。アクションやステータスタイプ、プロミス、スタッキング、スワイプでの閉じる操作に対応しています。

<ComponentPreview styleName="base-nova" name="toast-demo" />

CLI を使用してプロジェクトに追加します。

```bash
npx shadcn@latest add toast
```

**レジストリはサーバー側で検索を処理できるようになりました。**

`shadcn search` を実行すると、CLI は検索パラメータをクエリ パラメータとしてレジストリに送信します。

```txt
GET /r/registry.json?q=button&limit=50&offset=0
```

レジストリは、一致するアイテムを `pagination` オブジェクトとともに返します。CLI はその結果をそのまま表示します。これにより、大規模なレジストリでの検索が高速化され、検索のためにカタログ全体をダウンロードする必要もなくなります。

```json title="registry.json?q=button&limit=1"
{
  "name": "acme",
  "homepage": "https://acme.com",
  "items": [
    {
      "name": "button",
      "type": "registry:ui",
      "description": "A button component."
    }
  ],
  "pagination": {
    "total": 12,
    "offset": 0,
    "limit": 1,
    "hasMore": true
  }
}
```

動的検索はオプトインです。静的レジストリはクエリ パラメータを無視し、何も変更しなくてもそのまま動作し続けます。

詳細については、[動的検索](/docs/registry/dynamic-search) ドキュメントを参照してください。

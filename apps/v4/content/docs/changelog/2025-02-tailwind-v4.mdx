Tailwind v4 と React 19 の最初のプレビューを出荷しました。今日から早速お試しいただけます。

新着情報：

- CLI は、Tailwind v4 を使用してプロジェクトを初期化できるようになりました。
- 新しい @theme ディレクティブと @theme インライン オプションを完全にサポートします。
- すべてのコンポーネントが Tailwind v4 および React 19 用に更新されました。
- forwardRefs を削除し、型を調整しました。
- すべてのプリミティブにスタイル設定用のデータスロット属性が追加されました。
- コンポーネントのスタイルを修正し、クリーンアップしました。
- Sonner を優先して、トーストコンポーネントを廃止します。
- ボタンはデフォルトのカーソルを使用するようになりました。
- デフォルトのスタイルは廃止予定です。新しいプロジェクトでは new-york を使用します。
- HSL カラーが OKLCH に変換されるようになりました。

詳細については、[ドキュメント](/docs/tailwind-v4) を参照してください。

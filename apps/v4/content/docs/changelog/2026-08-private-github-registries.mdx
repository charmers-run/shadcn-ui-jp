**GitHub レジストリがプライベート リポジトリで動作するようになりました。**

6 月に、あらゆるパブリック GitHub リポジトリをレジストリに変換できる機能を提供しました。チームからは、公開すべきではないデザインシステムや機能キット、エージェントのルールや規約といった内部コードについても、同じことができるようにしてほしいという要望がありました。

プライベート リポジトリからインストールできるようになりました。リポジトリを読み取れる場合は、
CLI はそこからインストールできます。

```bash
npx shadcn@latest add acme/internal-toolkit/auth-kit
```

## ゼロ構成

GitHub CLI にログインしている場合は、何も設定する必要はありません。

```bash
gh auth login
```

リポジトリが公開されていない場合、CLI は `gh` に保存されている認証情報を使ってリポジトリを読み取ります。トークンは GitHub CLI の内部にとどまり、shadcn のプロセスに渡ることは一切ありません。

```txt
✔ Using gh credentials.
✔ Checking registry.
✔ Created 1 file:
  - lib/auth.ts
```

## CI サポート

GitHub CLI がインストールされていない場合は、`GH_TOKEN` または `GITHUB_TOKEN` を設定します。

```bash
GH_TOKEN=github_pat_xxx npx shadcn@latest add acme/internal-toolkit/auth-kit
```

**コンテンツ: 読み取り専用** アクセス権を持つ、リポジトリにスコープされたきめ細かい個人アクセス トークンの使用をお勧めします。

## すべてのコマンドで動作します

プライベート リポジトリは、パブリック GitHub レジストリと同じコマンドで動作します。

```bash
npx shadcn@latest list acme/internal-toolkit
```

```bash
npx shadcn@latest search acme/internal-toolkit --query auth
```

```bash
npx shadcn@latest view acme/internal-toolkit/auth-kit
```

```bash
npx shadcn@latest registry validate acme/internal-toolkit
```

## 仕組み

- パブリック リポジトリは、以前とまったく同じように匿名で読み取られます。認証情報は一切使用されず、GitHub CLI が呼び出されることもありません。
- CLI はまず匿名アクセスを試み、リポジトリが公開されていない場合にのみ認証情報を使用します。
- プライベート ファイルは GitHub のコンテンツ API を通じて読み取られ、解決されたコミット SHA に固定されます。
- `GH_TOKEN` からのトークンは、`api.github.com` にのみ送信されます。保存された GitHub CLI の認証情報は、shadcn の CLI ではなく `gh` 自身によって読み取られます。

完全なガイドについては、[プライベート リポジトリ](/docs/registry/github#private-repositories) のドキュメントを参照してください。

本日、マルチステップの質問フロー用の新しいコンポーネント [**Questionnaire**](/docs/components/base/questionnaire) をリリースしました。エージェントの確認プロンプトやオンボーディング、アンケート、受付フォーム、設定などに使用できます。

アンケートは、Base UI、React Aria、Radix の全 8 スタイルで利用できます。

/>

## 特徴

- ネイティブなラジオボタンとチェックボックスによる単一選択および複数選択。
- 固定の選択肢と自由形式の回答。
- 任意の質問を明示的にスキップする機能。
- 前へ、次へ、送信、およびカスタム進行状況コントロール。
- 必須項目とカスタム検証。
- 制御されたナビゲーション、保存されたデフォルト、および条件付きの質問。
- オプションの文字または数字のショートカットを使用したキーボード ナビゲーション。
- ネイティブ フォームのシリアル化とサーバーでレンダリングされたコレクション状態。
- スタンドアロン、カード、ダイアログの構成。

## インストール

```bash
npx shadcn@latest add questionnaire
```

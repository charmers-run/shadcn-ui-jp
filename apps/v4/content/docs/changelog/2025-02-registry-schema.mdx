---

より多くの機能をサポートするためにレジストリスキーマを更新しています。

コードをフラットな JSON ファイルとして定義し、CLI 経由で配布します。

- カスタム スタイル: 独自のデザインシステム、コンポーネント、トークンを導入します。
- サードパーティのレジストリや LLM のコンポーネントを拡張、上書きし、自由に組み合わせて利用できます。
- テーマ、CSS 変数、フック、アニメーション、Tailwind レイヤーとユーティリティをインストールします。

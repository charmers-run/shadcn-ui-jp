`Message` コンポーネントは、会話内の 1 つのメッセージをレイアウトします。メッセージ表示部分の周囲にあるアバター、配置、ヘッダー、フッターを扱います。

AI アプリケーションでは、`Message` コンポーネントを使って推論ステップ、ツール呼び出し、アシスタントメッセージをレンダリングできます。

## 使い方

```tsx showLineNumbers
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
import { Bubble, BubbleContent } from "@/components/ui/bubble"
import { Message, MessageAvatar, MessageContent } from "@/components/ui/message"
```

```tsx showLineNumbers
<Message>
  <MessageAvatar>
    <Avatar>
      <AvatarImage src="https://github.com/shadcn.png" alt="@shadcn" />
      <AvatarFallback>CN</AvatarFallback>
    </Avatar>
  </MessageAvatar>
  <MessageContent>
    <Bubble>
      <BubbleContent>How can I help you today?</BubbleContent>
    </Bubble>
  </MessageContent>
</Message>
```

**注意:** `Message` は行のレイアウト（アバター、配置、ヘッダー、フッター）を管理します。
実際に表示されるメッセージ本体は、内部に配置した
[`Bubble`](/docs/components/bubble) でレンダリングしてください。会話全体を囲むスクロールコンテナには
[`MessageScroller`](/docs/components/message-scroller) を使用します。

## 構成

メッセージを作成するには、次の構成を使用します。

```text
Message
├── MessageAvatar
└── MessageContent
    ├── MessageHeader
    ├── Bubble
    └── MessageFooter
```

同じ送信者からの連続メッセージをスタックするには、`MessageGroup` を使用します。

```text
MessageGroup
├── Message
└── Message
```

## 機能

- `align` プロップによる、送信者側・受信者側の行の先頭/末尾揃え
- メッセージの下端に固定され、フッターと重ならないアバタースロット
- 送信者名やステータス、メッセージアクション用のヘッダー・フッタースロット
- フッターはメッセージ側に追従し、`align="end"` の行でもアクションの位置が揃います
- 同じ送信者からの連続メッセージをまとめて表示するグループラッパー
- すべてのパーツに用意された `className` プロップによるカスタマイズ可能なスタイル

## アバター

`MessageAvatar` を使用して、メッセージの横にアバターをレンダリングします。アバターをメッセージの最後に揃えるには、メッセージに `align="end"` を設定します。

| align   | Description                                         |
| ------- | --------------------------------------------------- |
| `start` | メッセージを会話の先頭に揃えます。 |
| `end`   | メッセージを会話の末尾に揃えます。 |

## グループ

`MessageGroup` を使用して、同じ送信者からの連続したメッセージをスタックします。前のメッセージに空の `MessageAvatar` をレンダリングして、最後のメッセージのアバターと位置を合わせます。

## アクセシビリティ

`Message` はレイアウトのための装飾的なラッパーです。アクセシビリティは、その内部に配置するコンテンツによって決まります。

### アイコンのみのアクションにラベルを付ける

`MessageFooter` 内のアクションボタンは通常アイコンのみなので、それぞれに `aria-label` を付けてください。

```tsx showLineNumbers
<MessageFooter>
  <Button variant="ghost" size="icon" aria-label="Copy">
    <CopyIcon />
  </Button>
</MessageFooter>
```

### ステータス更新

処理中のメッセージには、`role="status"` を指定した [`Marker`](/docs/components/marker) を使用し、更新が表示された際に支援技術が読み上げるようにします。

```tsx showLineNumbers
<Message>
  <Marker role="status">
    <MarkerIcon>
      <Spinner />
    </MarkerIcon>
    <MarkerContent>Checking the logs...</MarkerContent>
  </Marker>
</Message>
```

## API リファレンス

### メッセージ

メッセージ行ラッパー。

| Prop        | Type               | Default   | Description                                       |
| ----------- | ------------------ | --------- | ------------------------------------------------- |
| `align`     | `"start" \| "end"` | `"start"` | The alignment of the message in the conversation. |
| `className` | `string`           | -         | Additional classes to apply to the row.           |

### MessageGroup

Groups consecutive messages from the same sender.

| Prop        | Type     | Default | Description                                    |
| ----------- | -------- | ------- | ---------------------------------------------- |
| `className` | `string` | -       | Additional classes to apply to the group root. |

### MessageAvatar

アバタースロット。メッセージの下部に配置されます。メッセージに `MessageFooter` が含まれている場合、アバターは上に移動して、フッターではなくメッセージの表面に合わせて配置されます。

| Prop        | Type     | Default | Description                                     |
| ----------- | -------- | ------- | ----------------------------------------------- |
| `className` | `string` | -       | Additional classes to apply to the avatar slot. |

### MessageContent

Wraps the header, message surface, and footer.

| Prop        | Type     | Default | Description                                      |
| ----------- | -------- | ------- | ------------------------------------------------ |
| `className` | `string` | -       | Additional classes to apply to the content slot. |

### MessageHeader

メッセージの上に送信者名などのコンテンツを表示します。`align` に関係なく、先頭に揃えられます。

| Prop        | Type     | Default | Description                                |
| ----------- | -------- | ------- | ------------------------------------------ |
| `className` | `string` | -       | Additional classes to apply to the header. |

### MessageFooter

Displays content below the message, such as status or actions. Aligns to the message side.

| Prop        | Type     | Default | Description                                |
| ----------- | -------- | ------- | ------------------------------------------ |
| `className` | `string` | -       | Additional classes to apply to the footer. |

## 使い方

```tsx
import { ToggleGroup, ToggleGroupItem } from "@/components/ui/toggle-group"
```

```tsx
<ToggleGroup type="single">
  <ToggleGroupItem value="a">A</ToggleGroupItem>
  <ToggleGroupItem value="b">B</ToggleGroupItem>
  <ToggleGroupItem value="c">C</ToggleGroupItem>
</ToggleGroup>
```

## 構成

`ToggleGroup` を構築するには、次の構成を使用します。

```text
ToggleGroup
├── ToggleGroupItem
└── ToggleGroupItem
```

## 変更ログ

### 2026-05-17 デフォルトの間隔

デフォルトの `spacing` を `0` から `2` に変更し、デフォルトで項目間にスペースを入れてトグル グループが表示されるようにしました。接続された項目には `spacing={0}` を使用します。

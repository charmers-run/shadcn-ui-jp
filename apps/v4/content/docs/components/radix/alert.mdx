## 使用法

```tsx showLineNumbers
import {
  Alert,
  AlertAction,
  AlertDescription,
  AlertTitle,
} from "@/components/ui/alert"
```

```tsx showLineNumbers
<Alert>
  <InfoIcon />
  <AlertTitle>Heads up!</AlertTitle>
  <AlertDescription>
    You can add components and dependencies to your app using the cli.
  </AlertDescription>
  <AlertAction>
    <Button variant="outline">Enable</Button>
  </AlertAction>
</Alert>
```

## API リファレンス

### アラート

`Alert` コンポーネントは、ユーザーの注意を促すコールアウトを表示します。

| プロパティ  | タイプ                         | デフォルト     |
| --------- | ---------------------------- | ----------- |
| `variant` | `"default" \| "destructive"` | `"default"` |

### アラートタイトル

`AlertTitle` コンポーネントは、アラートのタイトルを表示します。

| プロパティ  | タイプ     | デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | - |

### アラートの説明

`AlertDescription` コンポーネントは、アラートの説明または内容を表示します。

| プロパティ  | タイプ     | デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | - |

### アラートアクション

`AlertAction` コンポーネントは、アラートの右上隅に絶対配置されたアクション要素 (ボタンなど) を表示します。

| プロパティ  | タイプ     | デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | - |

## 使い方

```tsx showLineNumbers
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@/components/ui/drawer"
```

```tsx showLineNumbers
<Drawer>
  <DrawerTrigger>Open</DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Are you absolutely sure?</DrawerTitle>
      <DrawerDescription>This action cannot be undone.</DrawerDescription>
    </DrawerHeader>
    <DrawerFooter>
      <Button>Submit</Button>
      <DrawerClose>
        <Button variant="outline">Cancel</Button>
      </DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

## 構成

次の構成を使用して `Drawer` を構築します。

```text
Drawer
├── DrawerTrigger
└── DrawerContent
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    └── DrawerFooter
```

## 位置

`direction` プロップを使用してドロワーの側面を設定します。使用可能なオプションは、`top`、`right`、`bottom`、および `left` です。

<ComponentPreview styleName="radix-nova" name="drawer-sides" />

## レスポンシブ

`Dialog` コンポーネントと `Drawer` コンポーネントを組み合わせて、応答性の高いダイアログを作成できます。これにより、デスクトップでは `Dialog` コンポーネントがレンダリングされ、モバイルでは `Drawer` がレンダリングされます。


## 構成

### シンプル

`NativeSelect` の直下に配置されるオプション (`NativeSelectOptGroup` はありません)。

```text
NativeSelect
├── NativeSelectOption
├── NativeSelectOption
├── NativeSelectOption
└── NativeSelectOption
```

### グループ付き

`NativeSelectOptGroup` を使用して、オプションをカテゴリーに整理します。

```text
NativeSelect
├── NativeSelectOptGroup
│   ├── NativeSelectOption
│   └── NativeSelectOption
└── NativeSelectOptGroup
    ├── NativeSelectOption
    └── NativeSelectOption
```

## NativeSelect と Select の違い

- ネイティブブラウザーの動作、優れたパフォーマンス、モバイルに最適化されたドロップダウンが必要な場合は `NativeSelect` を使用してください。
- カスタムスタイル、アニメーション、複雑な操作が必要な場合は `Select` を使用してください。

## API リファレンス

### NativeSelect

ネイティブ HTML の選択要素をラップするメインの選択コンポーネント。

```tsx
<NativeSelect>
  <NativeSelectOption value="option1">Option 1</NativeSelectOption>
  <NativeSelectOption value="option2">Option 2</NativeSelectOption>
</NativeSelect>
```

### NativeSelectOption

選択内の個々のオプションを表します。

| Prop       | Type      | Default |
| ---------- | --------- | ------- |
| `value` | `string` |         |
| `disabled` | `boolean` | `false` |

### NativeSelectOptGroup

関連するオプションをグループ化し、整理しやすくします。

| Prop       | Type      | Default |
| ---------- | --------- | ------- |
| `label` | `string` |         |
| `disabled` | `boolean` | `false` |

```tsx
<NativeSelectOptGroup label="Fruits">
  <NativeSelectOption value="apple">Apple</NativeSelectOption>
  <NativeSelectOption value="banana">Banana</NativeSelectOption>
</NativeSelectOptGroup>
```

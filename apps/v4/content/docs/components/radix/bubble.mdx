`Bubble` コンポーネントは、フレーム化された会話コンテンツを表示します。チャット テキスト、短い構造化された出力、引用された返信、提案、反応に使用します。

フル機能のチャット インターフェイスの場合は、[`Message`](/docs/components/message) コンポーネントを使用します。`Bubble` は意図的にバブルの表面にスコープされています。アバター、名前、タイムスタンプ、メタデータ、メッセージ レベルのアクションを [`Message`](/docs/components/message) に配置します。

## 使い方

```tsx showLineNumbers
import { Bubble, BubbleContent, BubbleReactions } from "@/components/ui/bubble"
```

```tsx showLineNumbers
<Bubble>
  <BubbleContent>
    I checked the registry output and removed the stale route.
  </BubbleContent>
  <BubbleReactions>
    <span>👍</span>
  </BubbleReactions>
</Bubble>
```

## 構成

バブルを構築するには、次の構成を使用します。

```text
Bubble
├── BubbleContent
└── BubbleReactions
```

`BubbleGroup` を使用して、同じ送信者からの連続するバブルをグループ化します。

```text
BubbleGroup
├── Bubble
│   └── BubbleContent
└── Bubble
    └── BubbleContent
```

## 機能

- 強力なプライマリバブルからフレームのないゴーストコンテンツまで、7 つのビジュアルバリアント
- 送信側バブルと受信側バブルの開始と終了の位置合わせ
- 構成可能な側面と位置合わせによりバブルのエッジに固定されるリアクション
- バブルのサイズは、コンテナの幅の最大 80% まで、内容に応じて変わります
- リンクおよびボタン バブルの `asChild` によるポリモーフィック コンテンツ
- 各パーツの `className` プロップによるカスタマイズ可能なスタイル

## バリアント

`variant` を使用して、バブルの視覚的な処理を変更します。

<ComponentPreview
  styleName="radix-rhea"
  name="bubble-variants"
  previewClassName="h-auto theme-blue"
/>

|バリアント |説明 |
| ------------- | ------------------------------------------------------ |
| `default` |通常、現在のユーザー向けの強力なプライマリ バブル。 |
| `secondary` |会話コンテンツの標準的なニュートラルバブル。  |
| `muted` |静かなサポートコンテンツのための強調度の低いバブル。  |
| `tinted` |プライマリカラーを控えめに帯びたバブル。                        |
| `outline` |二次コンテンツまたはリッチコンテンツ用の枠付きバブル。       |
| `ghost` |アシスタント テキストまたはリッチ コンテンツのフレームなしコンテンツ。   |
| `destructive` |エラーまたは失敗したアクションの破壊的なバブル。      |

バブルのサイズは、コンテナの幅の最大 80% まで、内容に応じて変わります。`ghost` バリアントは最大幅を削除するため、アシスタント テキストとリッチ コンテンツが行全体に広がることができます。

## 位置合わせ

`Bubble` で `align` を使用して、バブルを会話の開始または終了に位置合わせします。

<ComponentPreview
  styleName="radix-rhea"
  name="bubble-alignment"
  previewClassName="h-auto theme-blue"
/>

|整列 |説明 |
| ------- | -------------------------------------------------- |
| `start` |バブルを会話の開始に合わせます。 |
| `end`   |バブルを会話の終了に合わせます。   |

**注意:** チャット インターフェイスを構築するときは、おそらく `Bubble` コンポーネントではなく、`Message` コンポーネント自体で位置合わせを使用することをお勧めします。`Message` コンポーネントの `role` プロパティを使用すると、バブルを会話の開始または終了に自動的に配置できます。

## バブルグループ

同じ送信者からの連続したバブルをグループ化するには、`BubbleGroup` を使用します。`align` プロパティは、`BubbleGroup` コンポーネントではなく、`Bubble` コンポーネント自体に設定する必要があることに注意してください。

```text
BubbleGroup
├── Bubble
│   └── BubbleContent
└── Bubble
    └── BubbleContent
```

## リンクとボタン

`BubbleContent` の `asChild` プロップを使用すると、バブルをリンクまたはボタンに変えることができます。

<ComponentPreview
  styleName="radix-rhea"
  name="bubble-link-button"
  previewClassName="h-auto theme-blue"
/>

```tsx showLineNumbers
import { Bubble, BubbleContent } from "@/components/ui/bubble"

export function BubbleLinkDemo() {
  return (
    <Bubble variant="muted">
      <BubbleContent asChild>
        <button>Click here</button>
      </BubbleContent>
    </Bubble>
  )
}
```

## リアクション

バブルのリアクションには `BubbleReactions` を使用します。これを使用して、リアクションやクイック アクション ボタンを表示できます。 `side` および `align` を使用して行を配置します。`side="top"` は行を上端に固定します。リアクションはバブルの端に重なるため、行の間に垂直方向のスペースを残してください。この理由から、以下の例ではより大きな `gap` を使用しています。

## アクセシビリティ

`Bubble` は、プレゼンテーション用のメッセージ サーフェスをレンダリングします。周囲のコンテナーで会話レベルのセマンティクスを維持し、以下のガイドラインに従ってください。

### リアクションのラベル付け

リアクションは絵文字の行として表示されます。スクリーン リーダーはコンテキストなしで各グリフを読み取り、`+8` のようなカウンターは「プラス 8」としてアナウンスされます。説明的な `aria-label` を含む単一の画像として行をグループ化し、一度にアナウンスされるようにします。`role="img"` は支援技術から個々の絵文字も非表示にするため、`aria-hidden` は必要ありません。

```tsx showLineNumbers
<BubbleReactions role="img" aria-label="Reactions: thumbs up, fire, and 8 more">
  <span>👍</span>
  <span>🔥</span>
  <span>+8</span>
</BubbleReactions>
```

リアクションがインタラクティブである場合、代わりにボタンをレンダリングし、アイコンのみのボタンに `aria-label` を与えます。

```tsx showLineNumbers
<BubbleReactions>
  <Button aria-label="Thumbs up" variant="secondary" size="icon-xs">
    <ThumbsUpIcon />
  </Button>
</BubbleReactions>
```

### インタラクティブなバブル

バブルをクリックできる場合は、`asChild` プロップを使用して実際の `<button>` または `<a>` としてレンダリングし、フォーカス可能にして正しいロールを公開します。`BubbleContent` にはインタラクティブ要素用の可視フォーカス リングが同梱されており、アクセス可能な名前はバブル テキストに由来します。追加のラベルは必要ありません。

```tsx showLineNumbers
<Bubble variant="muted" align="end">
  <BubbleContent asChild>
    <button type="button" onClick={onReply}>
      I forgot my password
    </button>
  </BubbleContent>
</Bubble>
```

### 色を超えた意味

バブルのバリアントは、色で役割とトーンを示します。色だけで意味が伝わらないように、テキスト、配置、アイコンと組み合わせてください。`destructive` バブルの場合は、色の処理に依存するのではなく、メッセージ テキストにエラー コンテキストを保持します。

## API リファレンス

### バブル

ルートバブルラッパー。

|小道具 |タイプ |デフォルト |説明 |
| ----------- | ------------------------------------------------------------------------------------------ | ----------- | ------------------------------------------------ |
| `variant`   | `"default" \| "secondary" \| "muted" \| "tinted" \| "outline" \| "ghost" \| "destructive"` | `"default"` |バブルの視覚処理。                     |
| `align`     | `"start" \| "end"`                                                                         | `"start"`   |バブルのインライン配置。              |
| `className` | `string`                                                                                   | -           |ルート要素に適用する追加のクラス。 |

### バブルコンテンツ

バブルコンテンツラッパー。

|小道具 |タイプ |デフォルト |説明 |
| ----------- | --------- | ------- | --------------------------------------------------- |
| `asChild`   | `boolean` | `false` |コンテンツを子要素としてレンダリングします。            |
| `className` | `string`  | -       |コンテンツ要素に適用する追加のクラス。 |

### バブルリアクション

バブルの重複するリアクションを表示します。

|小道具 |タイプ |デフォルト |説明 |
| ----------- | ------------------- | ---------- | ------------------------------------------------ |
| `side`      | `"top" \| "bottom"` | `"bottom"` |リアクションを固定するバブルの側面。  |
| `align`     | `"start" \| "end"`  | `"end"`    |リアクションのインライン配置。           |
| `className` | `string`            | -          |リアクション行に適用する追加のクラス。 |

### BubbleGroup

同じ送信者からの連続するバブルをグループ化します。

|小道具 |タイプ |デフォルト |説明 |
| ----------- | -------- | ------- | ---------------------------------------------- |
| `className` | `string` | -       |グループ ルートに適用する追加のクラス。 |

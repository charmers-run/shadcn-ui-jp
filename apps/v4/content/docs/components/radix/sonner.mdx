## インストール

<TabsList>
  <TabsTrigger value="cli">コマンド</TabsTrigger>
  <TabsTrigger value="manual">手動</TabsTrigger>

<TabsContent value="cli">

<Steps className="mb-0 pt-2">

<Step>次のコマンドを実行します。</Step>

```bash
npx shadcn@latest add sonner
```

<Step>Toaster コンポーネントを追加します。</Step>

```tsx title="app/layout.tsx" {1,9} showLineNumbers
import { Toaster } from "@/components/ui/sonner"

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <head />
      <body>
        <main>{children}</main>
        <Toaster />
      </body>
    </html>
  )
}
```

</Steps>

</TabsContent>

<TabsContent value="manual">

<Steps className="mb-0 pt-2">

<Step>次の依存関係をインストールします。</Step>

```bash
npm install sonner next-themes
```

<Step>次のコードをコピーしてプロジェクトに貼り付けます。</Step>

<ComponentSource
  name="sonner"

```tsx showLineNumbers title="app/layout.tsx" {1,8}
import { Toaster } from "@/components/ui/sonner"

  return (
    <html lang="en">

      </body>

```

</Steps>

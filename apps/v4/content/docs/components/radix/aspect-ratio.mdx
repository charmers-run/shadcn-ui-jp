## 使用法

```tsx showLineNumbers
import { AspectRatio } from "@/components/ui/aspect-ratio"
```

```tsx showLineNumbers
<AspectRatio ratio={16 / 9}>
  <Image src="..." alt="Image" className="rounded-md object-cover" />
</AspectRatio>
```

## 正方形

`ratio={1 / 1}` プロップを使用した正方形のアスペクト比コンポーネント。画像を正方形で表示する場合に便利です。

## API リファレンス

### アスペクト比

`AspectRatio` コンポーネントは、希望の比率でコンテンツを表示します。

| プロップ | タイプ | デフォルト | 必須 |
| ----------- | -------- | ------- | -------- |
| `ratio`     | `number` | -       | はい     |
| `className` | `string` | - |いいえ |

[Radix UI](https://www.radix-ui.com/primitives/docs/components/aspect-ratio#api-reference) のドキュメントで詳細を確認できます。

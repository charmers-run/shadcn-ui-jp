## カーソル

Tailwind v4 では、ボタン コンポーネントの `cursor: pointer` が `cursor: default` に[切り替わりました](https://tailwindcss.com/docs/upgrade-guide#buttons-use-the-default-cursor)。

`cursor: pointer` の動作を維持したい場合は、CSS ファイルに次のコードを追加します。

プロジェクトのセットアップ中に `npx shadcn@latest init --pointer` を使用してこれを有効にすることもできます。

```css showLineNumbers title="globals.css"
@layer base {
  button:not(:disabled),
  [role="button"]:not(:disabled) {
    cursor: pointer;
  }
}
```

## リンクとして

`buttonVariants` ヘルパーを使用すると、リンクをボタンのように見せることができます。

**リンクには `<Button render={<a />} nativeButton={false} />` を使用しないでください。** Base UI の `Button` コンポーネントは常に `role="button"` を適用し、`<a>` 要素のセマンティック リンク ロールをオーバーライドします。代わりに、プレーンの `<a>` タグとともに `buttonVariants` を使用してください。

## API リファレンス

### ボタン

`Button` コンポーネントは、さまざまなスタイルと機能を追加する `button` 要素のラッパーです。

|小道具 |タイプ |デフォルト |
| --------- | ------------------------------------------------------------------------------------ | ----------- |
| `variant` | `"default" \| "outline" \| "ghost" \| "destructive" \| "secondary" \| "link"`        | `"default"` |
| `size` | `"default" \| "xs" \| "sm" \| "lg" \| "icon" \| "icon-xs" \| "icon-sm" \| "icon-lg"` | `"default"` |

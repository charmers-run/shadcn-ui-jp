## 使い方

```tsx showLineNumbers
import {
  Select,
  SelectContent,
  SelectGroup,
  SelectItem,
  SelectTrigger,
  SelectValue,
} from "@/components/ui/select"
```

```tsx showLineNumbers
const items = [
  { label: "Light", value: "light" },
  { label: "Dark", value: "dark" },
  { label: "System", value: "system" },
]

<Select items={items}>
  <SelectTrigger className="w-[180px]">
    <SelectValue placeholder="Theme" />
  </SelectTrigger>
  <SelectContent>
    <SelectGroup>
      {items.map((item) => (
        <SelectItem key={item.value} value={item.value}>
          {item.label}
        </SelectItem>
      ))}
    </SelectGroup>
  </SelectContent>
</Select>
```

## 構成

次の構成を使用して、`Select` を構築します。

```text
Select
├── SelectTrigger
│   └── SelectValue
└── SelectContent
    ├── SelectGroup
    │   ├── SelectLabel
    │   ├── SelectItem
    │   └── SelectItem
    ├── SelectSeparator
    └── SelectGroup
        ├── SelectLabel
        ├── SelectItem
        └── SelectItem
```

## トリガーとの位置合わせ

`SelectContent` の `alignItemWithTrigger` を使用して、選択した項目をトリガーに揃えるかどうかを制御します。`true`(デフォルト)の場合、選択した項目がトリガーの上に表示されるようにポップアップが配置されます。`false` の場合、ポップアップはトリガーの端に揃えられます。

## 無効な状態

エラー状態を表示するには、`Field` コンポーネントに `data-invalid` 属性を追加し、`SelectTrigger` コンポーネントに `aria-invalid` 属性を追加します。

```tsx showLineNumbers /data-invalid/ /aria-invalid/
<Field data-invalid>
  <FieldLabel>Fruit</FieldLabel>
  <SelectTrigger aria-invalid>
    <SelectValue />
  </SelectTrigger>
</Field>
```

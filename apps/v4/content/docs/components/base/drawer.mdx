## 使い方

```tsx showLineNumbers
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@/components/ui/drawer"
```

```tsx showLineNumbers
<Drawer>
  <DrawerTrigger render={<Button variant="outline" />}>Open</DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Are you absolutely sure?</DrawerTitle>
      <DrawerDescription>This action cannot be undone.</DrawerDescription>
    </DrawerHeader>
    <div className="p-4">{/* Content here */}</div>
    <DrawerFooter>
      <Button>Submit</Button>
      <DrawerClose render={<Button variant="outline" />}>Cancel</DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

## 構成

次の構成を使用して `Drawer` を構築します。

```text
Drawer
├── DrawerTrigger
└── DrawerContent
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    └── DrawerFooter
```

`DrawerContent` は、Base UI のポータル、オーバーレイ、ビューポート、ポップアップを組み合わせたものです。より低レベルの制御が必要な場合は、`DrawerPortal`、`DrawerOverlay`、`DrawerSwipeHandle` もエクスポートされています。

## カスタム サイズ

垂直方向のドロワーはコンテンツに合わせてサイズが決まり、デフォルトでは `calc(100dvh - 6rem)` が上限になります。サイド ドロワーはビューポート幅の `75%`、大きな画面では `24rem` を占めます。

垂直ドロワーの高さをカスタマイズするには、`DrawerContent` の `h-*` および `max-h-*` ユーティリティを使用します。

```tsx
<DrawerContent className="h-[50vh]">
```

サイド ドロワーの幅をカスタマイズするには、`DrawerContent` の `w-*` および `max-w-*` ユーティリティを使用します。

```tsx
<DrawerContent className="w-96">
```

同じコンポーネントが複数の方向でレンダリングされる場合、`data-[swipe-axis=*]` バリアントを使用してオーバーライドの範囲を 1 つの軸に設定します。

```tsx
<DrawerContent className="data-[swipe-axis=y]:max-h-[50vh] data-[swipe-axis=x]:w-96">
```

ドロワーの領域をスクロール可能にするには、スクロール コンテナーをフレックス アイテムにします。コンテンツサイズのドロワー内では解決されない `h-full` は避けてください。

```tsx
<DrawerContent>
  <DrawerHeader>...</DrawerHeader>
  <div className="flex-1 overflow-y-auto p-4">{/* Scrollable content */}</div>
  <DrawerFooter>...</DrawerFooter>
</DrawerContent>
```

## スタイリング

ドロワーは、スタイル レベルのカスタマイズ用の CSS 変数を公開します。 `DrawerContent` にサイズ変数を設定します。 CSS の `[data-slot=drawer-overlay]` にオーバーレイ変数を設定します。

| 変数                            | デフォルト              | 説明                                                                     |
| ------------------------------ | ---------------------- | ----------------------------------------------------------------------- |
| `--drawer-inset` | `0px` |ドロワーをビューポートの端から浮かせます。                              |
| `--drawer-bleed-background`    | `var(--color-popover)` | スワイプのオーバーシュート時にドロワーの背後の隙間を埋めます。                     |
| `--drawer-overlay-min-opacity` | `0` |最小オーバーレイ不透明度。スナップ ポイントが有効な場合のデフォルトは `0.5` です。 |

ドロワーは、`DrawerContent` の `data-[swipe-direction=down]:` やその子孫の `group-data-[swipe-axis=y]/drawer-popup:` などのバリアントでターゲットにできるデータ属性も設定します。

| 属性                       | 値                             | 設定されるタイミング                     |
| ------------------------- | ----------------------------- | ------------------------------------- |
| `data-swipe-direction` | `up`、`right`、`down`、`left` |いつも。                               |
| `data-swipe-axis` | `x`、`y` |いつも。                               |
| `data-snap-points`        | あり                       | ドロワーにスナップ ポイントがあります。           |
| `data-expanded` |あり |ドロワーが完全なスナップ ポイントにあります。 |
| `data-swiping`            | あり                       | スワイプが進行中です。               |
| `data-nested-drawer-open` |あり |入れ子のドロワーが上部に開きます。       |

## ネスト

別のドロワー内から新しいドロワーを開きます。親ドロワーはマウントされたまま残り、最前面のドロワーの背後に積み重なります。

## 非モーダル

`modal={false}` を設定すると、ドロワーが開いている間もページの残りの部分を操作できるようになります。`disablePointerDismissal` と組み合わせると、外側を押してもドロワーが閉じないようにできます。`modal="trap-focus"` を使用すると、スクロールやポインター操作を制限せずにドロワー内にフォーカスを維持できます。

<ComponentPreview styleName="base-rhea" name="drawer-non-modal" />

## スナップ ポイント

`snapPoints` を使用して、ドロワーを事前設定された高さにスナップします。 `0` と `1` の間の数字はビューポートの小数を表します。 `1` より大きい数値はピクセル値として扱われます。文字列値は `px` および `rem` 単位をサポートします。スナップ ポイントは垂直ドロワーに適用されます。

制御された `snapPoint` プロップと `onSnapPointChange` プロップを使用して、アクティブなスナップ ポイントを追跡します。完全なスナップ ポイントに達すると、ドロワーに `data-expanded` 属性が設定され、`data-expanded:` バリアントでスタイルを指定できます。

<ComponentPreview styleName="base-rhea" name="drawer-snap-points" />

## レスポンシブ

`Dialog` コンポーネントと `Drawer` コンポーネントを組み合わせて、応答性の高いダイアログを作成できます。これにより、デスクトップでは `Dialog` コンポーネントがレンダリングされ、モバイルでは `Drawer` がレンダリングされます。

## Vaul からの移行

Base ドロワーは現在 [Base UI](https://base-ui.com/react/components/drawer) を使用しています。以前のバージョンをインストールしていた場合は、以下の手順に従って使用箇所を更新してください。

<Steps>

<Step>依存関係を更新します。</Step>

```diff
- npm install vaul
+ npm install @base-ui/react
```

<Step>`direction` を `swipeDirection` に置き換えます。</Step>

`bottom` の代わりに `down` を使用し、`top` の代わりに `up` を使用します。`left` と `right` は変更ありません。

```diff
- <Drawer direction="bottom">
+ <Drawer swipeDirection="down">
```

<Step>`asChild` を `render` に置き換えます。</Step>

`DrawerTrigger` の場合は、トリガー要素を `render` プロップに渡します。

```diff
- <DrawerTrigger asChild>
-   <Button variant="outline">Open</Button>
- </DrawerTrigger>
+ <DrawerTrigger render={<Button variant="outline" />}>
+   Open
+ </DrawerTrigger>
```

`DrawerClose` の場合は、閉じる要素を `render` プロップに渡します。

```diff
- <DrawerClose asChild>
-   <Button variant="outline">Cancel</Button>
- </DrawerClose>
+ <DrawerClose render={<Button variant="outline" />}>
+   Cancel
+ </DrawerClose>
```

<Step>スナップ ポイントのプロップを更新します。</Step>

スナップ ポイントを使用している場合は、制御されたスナップ ポイントのプロップと、連続スナップ ポイントのプロップの名前を変更してください。

```diff
  <Drawer
    snapPoints={[0.25, 0.5, 1]}
-   activeSnapPoint={snapPoint}
-   setActiveSnapPoint={setSnapPoint}
-   snapToSequentialPoint
+   snapPoint={snapPoint}
+   onSnapPointChange={setSnapPoint}
+   snapToSequentialPoints
  >
```

<Step>アニメーションとフォーカスのプロップを更新します。</Step>

```diff
- <Drawer onAnimationEnd={(open) => setDone(open)}>
+ <Drawer onOpenChangeComplete={(open) => setDone(open)}>
```

```diff
- <DrawerContent onOpenAutoFocus={(event) => event.preventDefault()}>
+ <DrawerContent initialFocus={false}>
```

<Step>Vaul 専用のプロップを確認します。</Step>

`handleOnly`、`repositionInputs`、`shouldScaleBackground` に相当するものは、Base UI ドロワー API にはありません。必要な動作に応じて、`disablePointerDismissal`、`modal`、`snapPoints`、または制御された `open` 状態などの Base UI プロップを使用してください。

```diff
- <Drawer handleOnly repositionInputs={false} shouldScaleBackground>
+ <Drawer>
```

```diff
- <Drawer dismissible={false}>
+ <Drawer disablePointerDismissal>
```

<Step>カスタム データ属性セレクターを更新します。</Step>

Vaul の `data-vaul-drawer-direction` セレクターを、Base UI の `data-swipe-direction` セレクターに置き換えます。

```diff
- <DrawerContent className="data-[vaul-drawer-direction=bottom]:max-h-[50vh]">
+ <DrawerContent className="data-[swipe-direction=down]:max-h-[50vh]">
```

Base UI は、スワイプとトランジションの状態に応じて `data-swiping`、`data-starting-style`、`data-ending-style` も公開します。`DrawerContent` の子孫では、軸ごとのスタイル指定に `group-data-[swipe-axis=x]/drawer-popup` と `group-data-[swipe-axis=y]/drawer-popup` を使用できます。

</Steps>

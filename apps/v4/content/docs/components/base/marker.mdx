## 構成

マーカーを作成するには、次の構成を使用します。

```text
Marker
├── MarkerIcon
└── MarkerContent
```

## 機能

- インラインマーカー、境界線付きの行、ラベル付き区切りのバリエーション
- 支援技術からは隠される装飾用のアイコンスロット
- リンクやボタンのマーカー用に、`render` によるポリモーフィックなルート要素
- ストリーミング中のステータステキストに使える [`shimmer`](/docs/utils/shimmer) ユーティリティとの組み合わせ
- すべてのパーツに用意された `className` プロップによるカスタマイズ可能なスタイリング

## バリエーション

Use `variant` to switch between an inline marker, bordered row, and labeled separator.

| Variant     | Description                                          |
| ----------- | ---------------------------------------------------- |
| `default`   | An inline marker for status, notes, and actions.     |
| `border`    | A default marker with a bottom border under the row. |
| `separator` | A centered label with divider lines on each side.    |

## アクセシビリティ

`Marker` は既定では装飾的な要素です。適切なセマンティクスは使い方によって異なるため、単一の既定値に頼らず、用途に応じて role を選択してください。

### ステータスと進捗

「Thinking...」や実行中のツールのようなストリーミング中・進行中のマーカーには `role="status"` を設定し、更新が表示された際に支援技術が読み上げるようにします。`Marker` は `role` を内部の要素にそのまま渡します。

```tsx showLineNumbers
<Marker role="status">
  <MarkerIcon>
    <Spinner />
  </MarkerIcon>
  <MarkerContent>Compacting conversation</MarkerContent>
</Marker>
```

### ラベル付き区切り

日付やセクションラベルなど、テキストを伴う区切りには role は不要です。区切り線は装飾用の CSS 疑似要素であり、テキストは通常のコンテンツとして読み上げられます。

```tsx showLineNumbers
<Marker variant="separator">
  <MarkerContent>Today</MarkerContent>
</Marker>
```

<Callout>
  **注意:** ラベル付きの区切りに `role="separator"` を追加しないでください。
  separator はテキストではなく `aria-label` からアクセシブルネームを取得し、
  その内容は装飾として扱われるため、表示されているラベルは読み上げられません。
  `role="separator"` は、意味のあるテキストを持たない区切りのために取っておいてください。
</Callout>

### 境界線付きマーカー

境界線付きマーカーは、デフォルトマーカーと同じセマンティクスを保ちます。下部の境界線は装飾のためのものなので、マーカーの用途に応じて `role="status"`、`render`、または role なしのいずれかを選択してください。

```tsx showLineNumbers
<Marker variant="border">
  <MarkerIcon>
    <FileTextIcon />
  </MarkerIcon>
  <MarkerContent>Opened implementation notes</MarkerContent>
</Marker>
```

### 装飾アイコン

`MarkerIcon` は装飾用であり、`aria-hidden` によって支援技術から隠されるため、意味は隣接する `MarkerContent` が担います。アイコンのみのマーカーには、空として読み上げられないように `aria-label` か目に見えるテキストを指定してください。

```tsx showLineNumbers
<Marker aria-label="Synced">
  <MarkerIcon>
    <CheckIcon />
  </MarkerIcon>
</Marker>
```

### インタラクティブなマーカー

マーカーがリンクやアクションのトリガーになる場合は、`render` プロップを使って実際の `<button>` や `<a>` としてレンダリングし、フォーカス可能にして正しい role を公開してください。アクセシブルネームはマーカーのテキストから取得されます。

```tsx showLineNumbers
<Marker render={<a href="/files" />}>
  <MarkerIcon>
    <FileTextIcon />
  </MarkerIcon>
  <MarkerContent>Explored 4 files</MarkerContent>
</Marker>
```

## API リファレンス

### Marker

The root marker element. The file also exports `markerVariants` for composing the marker styles into custom components.

| Prop        | Type                                   | Default     | Description                                      |
| ----------- | -------------------------------------- | ----------- | ------------------------------------------------ |
| `variant`   | `"default" \| "border" \| "separator"` | `"default"` | The marker layout.                               |
| `render`    | `ReactElement \| function`             | -           | Render as a different element, such as a link.   |
| `className` | `string`                               | -           | Additional classes to apply to the root element. |

### MarkerIcon

A decorative icon slot. Hidden from assistive tech with `aria-hidden`.

| Prop        | Type     | Default | Description                                   |
| ----------- | -------- | ------- | --------------------------------------------- |
| `className` | `string` | -       | Additional classes to apply to the icon slot. |

### MarkerContent

The marker text content.

| Prop        | Type     | Default | Description                                      |
| ----------- | -------- | ------- | ------------------------------------------------ |
| `className` | `string` | -       | Additional classes to apply to the content slot. |

サイドバーは、構築が最も複雑なコンポーネントの一つです。あらゆるアプリケーションの中核を担い、多くの可動部分を含むことがよくあります。

今では、それを支える確かな基盤が整いました。組み合わせ可能で、テーマ設定にも対応し、自由にカスタマイズできます。

[ブロックライブラリを見る](/blocks)。

## 使い方

```tsx showLineNumbers title="app/layout.tsx"
import { SidebarProvider, SidebarTrigger } from "@/components/ui/sidebar"
import { AppSidebar } from "@/components/app-sidebar"

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <SidebarProvider>
      <AppSidebar />
      <main>
        <SidebarTrigger />
        {children}
      </main>
    </SidebarProvider>
  )
}
```

## 構造

- **SidebarProvider** — 開閉状態を管理し、子コンポーネントにサイドバーのコンテキストを提供します。
- **Sidebar** — 折りたたみ可能なメインのサイドバーパネルです。
- **SidebarHeader** — 上部に固定表示され、ブランディングやタイトル、ワークスペース切り替えなどに使用します。
- **SidebarFooter** — 下部に固定表示され、ユーザーメニューや設定、アクションなどに使用します。
- **SidebarContent** — ヘッダーとフッターの間にあるスクロール可能な領域です。
- **SidebarGroup** — ラベル、アクション、コンテンツ領域を任意で持つ、関連するナビゲーションをグループ化します。
- **SidebarMenu** / **SidebarMenuItem** — リンク、バッジ、アクション、ネストされたサブメニューのためのメニュー構造です。
- **SidebarRail** — 該当する場合にサイドバーの幅を調整するためのリサイズハンドルです。
- **SidebarInset** — `inset` バリアントを使用する場合にメインコンテンツをラップします。
- **SidebarTrigger** — サイドバーの開閉を切り替えるコントロールです。

## SidebarProvider

`SidebarProvider` コンポーネントは、`Sidebar` コンポーネントにサイドバーのコンテキストを提供するために使用します。アプリケーション全体を必ず `SidebarProvider` コンポーネントでラップしてください。

### プロパティ

| Name           | Type                      | Description                                  |
| -------------- | ------------------------- | -------------------------------------------- |
| `defaultOpen`  | `boolean`                 | サイドバーのデフォルトの開閉状態です。           |
| `open`         | `boolean`                 | サイドバーの開閉状態です（制御時）。      |
| `onOpenChange` | `(open: boolean) => void` | サイドバーの開閉状態を設定します（制御時）。 |

### 幅

アプリケーション内にサイドバーが 1 つしかない場合は、`sidebar.tsx` の `SIDEBAR_WIDTH` と `SIDEBAR_WIDTH_MOBILE` 変数を使用してサイドバーの幅を設定できます。

```tsx showLineNumbers title="components/ui/sidebar.tsx"
const SIDEBAR_WIDTH = "16rem"
const SIDEBAR_WIDTH_MOBILE = "18rem"
```

アプリケーション内に複数のサイドバーがある場合は、`style` プロップで `--sidebar-width` と `--sidebar-width-mobile` の CSS 変数を使用できます。

```tsx showLineNumbers
<SidebarProvider
  style={
    {
      "--sidebar-width": "20rem",
      "--sidebar-width-mobile": "20rem",
    } as React.CSSProperties
  }
>
  <Sidebar />
</SidebarProvider>
```

### キーボードショートカット

サイドバーを開閉するには、Mac では `cmd+b`、Windows では `ctrl+b` のキーボードショートカットを使用します。

```tsx showLineNumbers title="components/ui/sidebar.tsx"
const SIDEBAR_KEYBOARD_SHORTCUT = "b"
```

## Sidebar

`Sidebar` は、折りたたみ可能なサイドバーをレンダリングするためのメインコンポーネントです。

### プロパティ

| Property      | Type                              | Description                       |
| ------------- | --------------------------------- | --------------------------------- |
| `side`        | `left` or `right`                 | サイドバーの表示位置です。          |
| `variant`     | `sidebar`, `floating`, or `inset` | サイドバーのバリアントです。       |
| `collapsible` | `offcanvas`, `icon`, or `none`    | サイドバーの折りたたみ状態です。 |

| Prop        | Description                                                  |
| ----------- | ------------------------------------------------------------ |
| `offcanvas` | 左右からスライドして表示される、折りたたみ可能なサイドバーです。 |
| `icon`      | アイコン表示に折りたたまれるサイドバーです。                           |
| `none`      | 折りたたみができないサイドバーです。                                   |

<Callout>
  **注:** `inset` バリアントを使用する場合は、メインコンテンツを必ず
  `SidebarInset` コンポーネントでラップしてください。
</Callout>

```tsx showLineNumbers
<SidebarProvider>
  <Sidebar variant="inset" />
  <SidebarInset>
    <main>{children}</main>
  </SidebarInset>
</SidebarProvider>
```

## useSidebar

`useSidebar` フックは、サイドバーを制御するために使用します。

```tsx showLineNumbers
import { useSidebar } from "@/components/ui/sidebar"

export function AppSidebar() {
  const {
    state,
    open,
    setOpen,
    openMobile,
    setOpenMobile,
    isMobile,
    toggleSidebar,
  } = useSidebar()
}
```

| Property        | Type                      | Description                                   |
| --------------- | ------------------------- | --------------------------------------------- |
| `state`         | `expanded` or `collapsed` | サイドバーの現在の状態です。             |
| `open`          | `boolean`                 | サイドバーが開いているかどうかです。                  |
| `setOpen`       | `(open: boolean) => void` | サイドバーの開閉状態を設定します。           |
| `openMobile`    | `boolean`                 | モバイルでサイドバーが開いているかどうかです。        |
| `setOpenMobile` | `(open: boolean) => void` | モバイルでのサイドバーの開閉状態を設定します。 |
| `isMobile`      | `boolean`                 | サイドバーがモバイル表示かどうかです。             |
| `toggleSidebar` | `() => void`              | サイドバーの開閉を切り替えます。デスクトップ・モバイル両対応です。      |

## SidebarGroup

`SidebarGroup` コンポーネントを使用して、サイドバー内にセクションを作成します。

`SidebarGroup` は、`SidebarGroupLabel`、`SidebarGroupContent`、そして任意で `SidebarGroupAction` を持ちます。

```tsx showLineNumbers
<SidebarGroup>
  <SidebarGroupLabel>Application</SidebarGroupLabel>
  <SidebarGroupAction>
    <Plus /> <span className="sr-only">Add Project</span>
  </SidebarGroupAction>
  <SidebarGroupContent></SidebarGroupContent>
</SidebarGroup>
```

`SidebarGroup` を折りたたみ可能にするには、`Collapsible` でラップします。

```tsx showLineNumbers
<Collapsible defaultOpen className="group/collapsible">
  <SidebarGroup>
    <SidebarGroupLabel render={<CollapsibleTrigger />}>
      Help
      <ChevronDown className="ml-auto transition-transform group-data-open/collapsible:rotate-180" />
    </SidebarGroupLabel>
    <CollapsibleContent>
      <SidebarGroupContent />
    </CollapsibleContent>
  </SidebarGroup>
</Collapsible>
```

## SidebarMenuButton

`SidebarMenuButton` コンポーネントは、`SidebarMenuItem` 内にメニューボタンをレンダリングするために使用します。

デフォルトでは、`SidebarMenuButton` はボタンをレンダリングしますが、`render` プロップを使用すると `Link` や `a` タグなど別のコンポーネントをレンダリングできます。

`isActive` プロップを使用して、メニュー項目をアクティブとしてマークします。

```tsx showLineNumbers

  Home
</SidebarMenuButton>
```

## SidebarTrigger

`SidebarTrigger` コンポーネントを使用して、サイドバーの開閉を切り替えるボタンをレンダリングします。

## 制御されたサイドバー

`open` と `onOpenChange` プロップを使用して、サイドバーを制御します。

```tsx showLineNumbers
export function AppSidebar() {
  const [open, setOpen] = React.useState(false)

  return (
    <SidebarProvider open={open} onOpenChange={setOpen}>
      <Sidebar />
    </SidebarProvider>
  )
}
```

## 変更履歴

### RTL サポート

以前のバージョンの `Sidebar` コンポーネントからアップグレードする場合は、RTL サポートを追加するために以下の変更を適用する必要があります。

<Steps>

<Step>`Sidebar` コンポーネントに `dir` プロップを追加します。</Step>

分割代入したプロップに `dir` を追加し、モバイル用の `SheetContent` に渡します。

```diff
  function Sidebar({
    side = "left",
    variant = "sidebar",
    collapsible = "offcanvas",
    className,
    children,
+   dir,
    ...props
  }: React.ComponentProps<"div"> & {
    side?: "left" | "right"
    variant?: "sidebar" | "floating" | "inset"
    collapsible?: "offcanvas" | "icon" | "none"
  }) {
```

続いて、モバイルビューの `SheetContent` に渡します。

```diff
  <Sheet open={openMobile} onOpenChange={setOpenMobile} {...props}>
    <SheetContent
+     dir={dir}
      data-sidebar="sidebar"
      data-slot="sidebar"
      data-mobile="true"
```

<Step>サイドバーコンテナに `data-side` 属性を追加します。</Step>

サイドバーコンテナ要素に `data-side={side}` を追加します。

```diff
  <div
    data-slot="sidebar-container"
+   data-side={side}
    className={cn(
```

<Step>サイドバーコンテナの配置用クラスを更新します。</Step>

JavaScript の三項演算子による条件付きクラスを、CSS のデータ属性セレクターに置き換えます。

```diff
  className={cn(
-   "fixed inset-y-0 z-10 hidden h-svh w-(--sidebar-width) transition-[left,right,width] duration-200 ease-linear md:flex",
-   side === "left"
-     ? "left-0 group-data-[collapsible=offcanvas]:left-[calc(var(--sidebar-width)*-1)]"
-     : "right-0 group-data-[collapsible=offcanvas]:right-[calc(var(--sidebar-width)*-1)]",
+   "fixed inset-y-0 z-10 hidden h-svh w-(--sidebar-width) transition-[left,right,width] duration-200 ease-linear md:flex data-[side=left]:left-0 data-[side=right]:right-0 data-[side=left]:group-data-[collapsible=offcanvas]:left-[calc(var(--sidebar-width)*-1)] data-[side=right]:group-data-[collapsible=offcanvas]:right-[calc(var(--sidebar-width)*-1)]",
```

<Step>`SidebarRail` の配置用クラスを更新します。</Step>

レールに物理的な配置を使用するよう、`SidebarRail` コンポーネントを更新します。

```diff
  className={cn(
-   "hover:after:bg-sidebar-border absolute inset-y-0 z-20 hidden w-4 -translate-x-1/2 transition-all ease-linear group-data-[side=left]:-end-4 group-data-[side=right]:start-0 after:absolute after:inset-y-0 after:start-1/2 after:w-[2px] sm:flex",
+   "hover:after:bg-sidebar-border absolute inset-y-0 z-20 hidden w-4 ltr:-translate-x-1/2 rtl:-translate-x-1/2 transition-all ease-linear group-data-[side=left]:-right-4 group-data-[side=right]:left-0 after:absolute after:inset-y-0 after:start-1/2 after:w-[2px] sm:flex",
```

<Step>`SidebarTrigger` のアイコンに RTL 反転を追加します。</Step>

`SidebarTrigger` 内のアイコンに `className="rtl:rotate-180"` を追加し、RTL モードで反転させます。

```diff
  <Button ...>
-   <PanelLeftIcon />
+   <PanelLeftIcon className="rtl:rotate-180" />
    <span className="sr-only">Toggle Sidebar</span>
  </Button>
```

</Steps>

これらの変更を適用すると、`dir` プロップを使用して方向を設定できるようになります。

```tsx
<Sidebar dir="rtl" side="right">
  {/* ... */}
</Sidebar>
```

これにより、サイドバーは LTR と RTL の両方のレイアウトで正しく配置され、操作にも適切に対応します。

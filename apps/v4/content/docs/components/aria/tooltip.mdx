## 使い方

```tsx showLineNumbers
import { Tooltip, TooltipTrigger } from "@/components/ui/tooltip"
```

```tsx showLineNumbers
<TooltipTrigger>
  <Button>Hover</Button>
  <Tooltip>
    <p>Add to library</p>
  </Tooltip>
</TooltipTrigger>
```

## 構成

`Tooltip` を構築するには、次の構成を使用します。

```text
TooltipTrigger
├── Button
└── Tooltip
```

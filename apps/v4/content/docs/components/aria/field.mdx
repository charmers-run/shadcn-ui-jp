```tsx showLineNumbers

  Field,
  FieldContent,
  FieldDescription,
  FieldError,
  FieldGroup,
```

```tsx showLineNumbers
<FieldSet>
  <FieldLegend>Profile</FieldLegend>
  <FieldDescription>This appears on invoices and emails.</FieldDescription>
  <FieldGroup>
    <Field>
      <FieldLabel htmlFor="name">Full name</FieldLabel>
      <Input id="name" autoComplete="off" placeholder="Evil Rabbit" />
      <FieldDescription>This appears on invoices and emails.</FieldDescription>
    </Field>
    <Field>
      <FieldLabel htmlFor="username">Username</FieldLabel>
      <Input id="username" autoComplete="off" aria-invalid />

      <Switch id="newsletter" />
      <FieldLabel htmlFor="newsletter">Subscribe to the newsletter</FieldLabel>
    </Field>
  </FieldGroup>
</FieldSet>
```

## 構成

### Field

ラベル、ヘルパー テキスト、および検証を含む単一のコントロール。

```text
Field
├── FieldLabel
├── Input / Textarea / Switch / Select
├── FieldDescription
└── FieldError
```

### FieldGroup

1 つのグループ内の関連フィールド。必要に応じて、セクション間で `FieldSeparator` を使用します。

```text
FieldGroup
├── Field
│   ├── FieldLabel
│   ├── Input / Textarea / Switch / Select
│   ├── FieldDescription
│   └── FieldError
├── FieldSeparator
└── Field
    ├── FieldLabel
    └── Input / Textarea / Switch / Select
```

### FieldSet

凡例と説明を含むセマンティック グループ。通常は `FieldGroup` が含まれます。

```text
FieldSet
├── FieldLegend
├── FieldDescription
└── FieldGroup
    ├── Field
    │   ├── FieldLabel
    │   ├── Input / Textarea / Switch / Select
    │   ├── FieldDescription
    │   └── FieldError
    └── Field
        ├── FieldLabel
        └── Input / Textarea / Switch / Select
```

## 構造

`Field` ファミリは、アクセシビリティ対応のフォームを作成するために設計されています。一般的なフィールドは次のように構成されています。

```tsx showLineNumbers
<Field>
  <FieldLabel htmlFor="input-id">Label</FieldLabel>
  {/* Input, Select, Switch, etc. */}
  <FieldDescription>Optional helper text.</FieldDescription>
  <FieldError>Validation message.</FieldError>
</Field>
```

- `Field` は、単一フィールドのコア ラッパーです。
- `FieldContent` は、ラベルと説明をグループ化するフレックス列です。記載がない場合は不要です。
- 関連フィールドを `FieldGroup` でラップし、セマンティック グループ化に `FieldSet` を `FieldLegend` とともに使用します。

## フォーム

`Field` コンポーネントと [React Hook Form](/docs/forms/react-hook-form)、[Tanstack Form](/docs/forms/tanstack-form)、または [Formisch](/docs/forms/formisch) を使用したフォームの構築については、[Form](/docs/forms) のドキュメントを参照してください。

## レスポンシブ レイアウト

- **垂直フィールド:** デフォルトの向きでは、ラベル、コントロール、ヘルパー テキストが縦に並びます。モバイルファーストのレイアウトに最適です。
- **水平フィールド:** ラベルとコントロールを並べて配置するには、`Field` に `orientation="horizontal"` を設定します。 `FieldContent` と組み合わせて説明を統一します。
- **レスポンシブ フィールド:** コンテナ対応の親内の自動列レイアウト用に `orientation="responsive"` を設定します。 `FieldGroup` に `@container/field-group` クラスを適用して、特定のブレークポイントで方向を切り替えます。

## 検証とエラー

- `data-invalid` を `Field` に追加して、ブロック全体をエラー状態に切り替えます。
- 支援技術のために、入力自体に `aria-invalid` を追加します。
- コントロールの直後または `FieldContent` 内に `FieldError` をレンダリングして、エラー メッセージをフィールドに合わせて配置します。

```tsx showLineNumbers /data-invalid/ /aria-invalid/
<Field data-invalid>
  <FieldLabel htmlFor="email">Email</FieldLabel>
  <Input id="email" type="email" aria-invalid />
  <FieldError>Enter a valid email address.</FieldError>
</Field>
```

## アクセシビリティ

- `FieldSet` および `FieldLegend` は、キーボードおよび支援技術ユーザー向けに関連するコントロールをグループ化します。
- `Field` は `role="group"` を出力するため、ネストされたコントロールは結合時に `FieldLabel` および `FieldLegend` からラベル付けを継承します。
- `FieldSeparator` は慎重に適用して、スクリーン リーダーが明確なセクション境界に遭遇するようにします。

## API リファレンス

### FieldSet

間隔プリセットを使用してセマンティック `fieldset` をレンダリングするコンテナー。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldSet>
  <FieldLegend>Delivery</FieldLegend>
  <FieldGroup>{/* Fields */}</FieldGroup>
</FieldSet>
```

### FieldLegend

`FieldSet` の凡例要素。ラベルのサイズに合わせて `label` バリアントに切り替えます。

| Prop        | Type                  | Default    |
| ----------- | --------------------- | ---------- |
| `variant`   | `"legend" \| "label"` | `"legend"` |
| `className` | `string`              |            |

```tsx
<FieldLegend variant="label">Notification Preferences</FieldLegend>
```

`FieldLegend` には、`legend` と `label` の 2 つのバリアントがあります。 `label` バリアントは、ラベルのサイズ変更と配置を適用します。 `FieldSet` をネストしている場合に便利です。

### FieldGroup

`Field` コンポーネントをスタックし、応答性の高い方向に対するコンテナー クエリを可能にするレイアウト ラッパー。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldGroup className="@container/field-group flex flex-col gap-6">
  <Field>{/* ... */}</Field>
  <Field>{/* ... */}</Field>
</FieldGroup>
```

### Field

単一フィールドのコア ラッパー。向きの制御、無効な状態のスタイル、および間隔を提供します。

| Prop           | Type                                          | Default      |
| -------------- | -------------------------------------------- | ------------ |
| `orientation`  | `"vertical" \| "horizontal" \| "responsive"` | `"vertical"` |
| `className`    | `string`                                     |              |
| `data-invalid` | `boolean`                                    |              |

```tsx
<Field orientation="horizontal">
  <FieldLabel htmlFor="remember">Remember me</FieldLabel>
  <Switch id="remember" />
</Field>
```

### FieldContent

ラベルがコントロールの横にあるときにコントロールと説明をグループ化するフレックス列。記載がない場合は不要です。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<Field>
  <Checkbox id="notifications" />
  <FieldContent>
    <FieldLabel htmlFor="notifications">Notifications</FieldLabel>
    <FieldDescription>Email, SMS, and push options.</FieldDescription>
  </FieldContent>
</Field>
```

### FieldLabel

直接入力とネストされた `Field` 子の両方に対してスタイル設定されたラベル。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldLabel htmlFor="email">Email</FieldLabel>
```

### FieldTitle

`FieldContent` 内にラベル スタイルを使用してタイトルをレンダリングします。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldContent>
  <FieldTitle>Enable Touch ID</FieldTitle>
  <FieldDescription>Unlock your device faster.</FieldDescription>
</FieldContent>
```

### FieldDescription

水平レイアウトで長い行のバランスを自動的に調整するヘルパー テキスト スロット。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldDescription>We never share your email with anyone.</FieldDescription>
```

### FieldSeparator

`FieldGroup` 内のセクションを区切る視覚的な区切り線。オプションのインライン コンテンツを受け入れます。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<FieldSeparator>Or continue with</FieldSeparator>
```

### FieldError

子または `errors` 配列 (例: `react-hook-form` から) を受け入れる、アクセス可能なエラー コンテナー。

| Prop        | Type                                        | Default |
| ----------- | ------------------------------------------ | ------- |
| `errors`    | `Array<{ message?: string } \| undefined>` |         |
| `className` | `string`                                   |         |

```tsx
<FieldError errors={errors.username} />
```

`errors` 配列に複数のメッセージが含まれている場合、コンポーネントはリストを自動的に表示します。

`FieldError` は、Zod、Valibot、ArkType など、[標準スキーマ](https://standardschema.dev/) を実装するバリデーターによって生成された問題も受け入れます。スキーマの結果から `issues` 配列を直接渡して、ライブラリ全体で統一されたエラー リストをレンダリングします。

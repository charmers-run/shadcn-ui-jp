## チェックされた状態

非制御のチェックボックスには `defaultSelected` を使用し、状態を制御するには `isSelected` と
`onChange` を使用します。

```tsx showLineNumbers
import * as React from "react"

export function Example() {
  const [checked, setChecked] = React.useState(false)

  return <Checkbox isSelected={checked} onChange={setChecked} />
}
```

## 無効な状態

チェックボックスに `isInvalid`、フィールド ラッパーに `data-invalid` を設定すると、
無効なスタイルが表示されます。

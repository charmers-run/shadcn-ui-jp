shadcn/ui を使用して構築を開始するためにできることがいくつかあります。

## コンポーネントを追加する

CLI を使用してコンポーネントをプロジェクトに追加します。

```bash
npx shadcn@latest add button
```

次に、それをインポートしてコード内で使用します。

```tsx title="app/page.tsx"
import { Button } from "@/components/ui/button"

export default function Home() {
  return <Button>Click me</Button>
}
```

従来のコンポーネントライブラリとは異なり、shadcn/ui はコンポーネントのソースコードを `components/ui/` の下のプロジェクトに直接追加します。コードはあなたが所有しており、必要に応じてカスタマイズできます。

複数のコンポーネントを一度に追加することも、使用可能なすべてのコンポーネントを追加することもできます。

```bash
npx shadcn@latest add button card input label
```

```bash
npx shadcn@latest add --all
```

[コンポーネント](/docs/components) ページですべてのコンポーネントを参照します。

## テーマをカスタマイズする

CSS ファイルでテーマを直接編集できます。CSS 変数やユーティリティクラスの使用方法について詳しくは [テーマ](/docs/theming) をご覧ください。

新しいプリセットを試したい場合は、[ui.shadcn.com](https://ui.shadcn.com) でカスタムテーマを視覚的に作成し、プリセットコードを使用してプロジェクトに適用できます。

```bash
npx shadcn@latest init --preset [CODE]
```

## ブロックを追加する

CLI を使用してプロジェクトにブロックを追加できます。

```bash
npx shadcn@latest add login-03
```

これにより、`login-03` ブロックがプロジェクトに追加されます。インポートしてコード内で使用します。

```tsx title="app/page.tsx"
import { Login03 } from "@/components/login-03"

export default function Home() {
  return <Login03 />
}
```

## レジストリからインストールする

shadcn/ui には、成長を続けるコミュニティレジストリのエコシステムがあります。CLI を使用して、任意のレジストリ URL からコンポーネントをインストールできます。

```bash
npx shadcn@latest add @[registry]/[name]
```

使用可能なレジストリのリストについては、[レジストリディレクトリ](/docs/directory) を参照してください。

## AI を使用して構築する

shadcn/ui は AI と連携するように設計されています。AI アシスタントは、プロジェクト内のコンポーネントのソースコードを読み取り、API を理解し、それらを組み合わせてページや機能を構築できます。

以下に、試してみるプロンプトの例をいくつか示します。

- _「名前、電子メール、パスワードを入力するフォームを備えたサインアップページを作成します。」_
- _「プロフィール情報を更新するためのフォームを含む設定ページを作成します。」_
- _「ヘッダー、統計カード、データテーブルを備えたダッシュボードを構築します。」_

## shadcn スキルをインストールする

AI アシスタントに shadcn スキルをインストールします。これにより、AI アシスタントは完全なコンポーネントレジストリ、ドキュメント、検索にアクセスできるようになります。

```bash
npx skills add shadcn/ui
```

[スキル](/docs/skills) の詳細をご覧ください。

## MCP サーバーに接続する

shadcn MCP サーバーにより、AI アシスタントは完全なコンポーネントレジストリ、ドキュメント、検索にアクセスできるようになります。エディターに接続すると、最高のエクスペリエンスが得られます。

```bash
npx shadcn@latest mcp init
```

詳細については、[MCP サーバー](/docs/mcp) ページをご覧ください。

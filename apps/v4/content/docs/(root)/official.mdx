shadcn/ui の公式 Web サイトは [ui.shadcn.com](https://ui.shadcn.com) です。

## 公式リソース

- **Web サイト:** [ui.shadcn.com](https://ui.shadcn.com) は、公式 Web サイトおよびコンポーネントのドキュメントです。
- **ソースコード:** [github.com/shadcn-ui/ui](https://github.com/shadcn-ui/ui) は、shadcn/ui および CLI の公式ソースリポジトリです。
- **CLI パッケージ:** [npmjs.com/package/shadcn](https://www.npmjs.com/package/shadcn) は、npm で公開されている公式 `shadcn` パッケージです。
- **プロジェクトの更新情報:** [@shadcn](https://twitter.com/shadcn) は、公式発表とプロジェクトの更新情報を公開します。

## サードパーティのリソース

コミュニティ Web サイトとレジストリは shadcn/ui コンポーネントまたは shadcn CLI を使用する場合がありますが、このページで shadcn/ui によって保守されていることが明示的に識別されていない限り、それらは独立しています。

プロジェクトにインストールする前に、サードパーティのコードを確認してください。コミュニティが管理するレジストリは、公式の [レジストリディレクトリ](/docs/directory) を参照してください。
